Учебный проект, выполненный в рамках курса по бизнес-аналитике. Цель — построить интерактивный отчёт в Power BI на основе исходного датасета: от загрузки и очистки данных до модели и визуализации ключевых показателей.
Задание:
1. Подгрузить файл data.csv в модель.
2. На первой странице должны быть 4 среза (определить какие), 4 суммирующие карточки (определить какие), таблица рейтинг по складам.
3. На этой же странице добавить кнопку, которая будет ссылаться на закладку. На закладке будет график динамика продаж по трем складам. На этой же закладке должна быть кнопка, которая будет вести обратно на таблицу.
4. На второй странице необходимо построить ABC анализ со срезами. На первой таблице будут основные данные по товарам, результаты ABC. На второй таблице Доли и суммы групп A, B, C. Для данной задачи можете создавать и добавлять новые таблицы.
